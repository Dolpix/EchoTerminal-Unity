# Overview

![Echo Terminal](echo_main_render.png)

Echo Terminal is a free, open source developer console for Unity 6.

Register commands with a single attribute. Get type-safe argument parsing, tab autocomplete, live syntax highlighting, and GameObject targeting — all out of the box. Every layer is replaceable.

---

## Key features

- **Attribute-based registration** — no manual wiring, no registries to maintain
- **Type-safe parsing** — built-in support for Unity types; extend with `ITokenParser`
- **Tab autocomplete** — type-based suggestions, inline hints, and fixed option lists
- **Live syntax highlighting** — configurable per-type color themes
- **GameObject targeting** — `@name` and `@all` autocomplete from the active scene
- **Command tags** — group and toggle commands at runtime
- **Fully replaceable UI** — swap out any layer or rebuild from scratch
